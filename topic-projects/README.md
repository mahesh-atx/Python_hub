# Topic projects — 2 basic + 1 hard each

This folder is **not** the mixed project packs.  
Each file trains **one topic**, with only **that topic + previous ones**.

| Per topic | Goal |
|-----------|------|
| **Basic 1 & 2** | Use the new tool until it feels normal (45–90 min each) |
| **Hard** | A tiny real program whose *spine* is this topic (2–4 hours) |

## How to practise

1. Finish that topic’s **question file** first (at least basics + intermediate).
2. Close the questions. Open a **blank** `.py` file.
3. Read **What it must do** once. Write steps as comments.
4. Build feature by feature. 10–15 minutes before hints.
5. Hard project: if you cannot do it closed-book, redo 4 questions, then retry.

One project = one file, e.g. `conditionals_b1_greeting.py`.

## Order (do not jump)

| File | You may use | You must not use |
|------|-------------|------------------|
| `01-conditional-statements.md` | variables, operators, `if` | loops, string methods, lists, `def` |
| `02-loops.md` | + `for`/`while`/`range` | string processing, lists, `def` |
| `03-strings.md` | + string methods | lists, `def`, `split` |
| `04-functions.md` | + `def`/`return` | lists, sets, dicts |
| `05-lists.md` | + lists | tuples as storage, sets, dicts |
| `06-tuples.md` | + tuples, `return a, b` | sets, dicts |
| `07-sets.md` | + sets | dicts |
| `08-dictionaries.md` | + dicts | comprehensions, files, classes |
| `09-comprehensions.md` | + comps | files, `try`, classes |
| `10-modules.md` | + `import`, your `.py` | data `open`, `try`, classes |
| `11-file-handling.md` | + `open`/JSON | `try` as main tool, classes |
| `12-exception-handling.md` | + `try`/`raise` | custom exception classes, `class` |
| `13-oop.md` | + classes | metaclasses / ABC |

String *values* (`"red"`) are allowed before Strings. Printing `"*"` in loops is allowed.

## After a topic’s 3 projects

If the **hard** one runs with the guide closed, you own that topic. Then go to the next file.
